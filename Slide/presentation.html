SLIDE 01 / 12

System Overview, Problem & Objectives

Addressing manual water monitoring vulnerabilities through software-based numerical modeling
P1: Imtiyaz Ali
Definition VIRTUAL STORAGE TANK

A software-based simulator that monitors and manages the water level of a virtual storage tank. No physical tank, pump or sensor is needed.

Problem Statement CRITICAL OPERATIONAL ISSUES
  • Manual monitoring causes overflow and unexpected shortage
  • Water distribution among pipes can be inefficient
  • Predicting levels and flows by hand needs complex, repeated calculation
Technical Scope CORE SYSTEM OBJECTIVES
  • 1. Mathematical Modeling: Model the tank with a differential equation
  • 2. Algorithm Implementation: Implement eight numerical methods
  • 3. Autonomous Control: Automate the pump to prevent overflow and shortage
  • 4. Predictive Horizons: Predict filling and emptying times
  • 5. Network Distribution: Calculate water flow through multiple pipes
  • 6. Rigorous Benchmarking: Compare accuracy, convergence and performance
GOAL Show the practical use of numerical methods in an intelligent water management system.
ZERO HARDWARE • 100% COMPUTATIONAL

Mathematical Model

Formulating conservation of mass for constant and non-linear head-dependent drainage
P1: Imtiyaz Ali
Governing Differential Equation
dV / dt = Qin − Qout
V = volume (L)  |  Qin = inflow, active only when pump is ON (L/min)  |  Qout = outflow (L/min)  |  t = time (min)
Boundary Conditions INITIAL PARAMETERS
Parameter Value
Tank Capacity 1000 L
Initial Volume (V0) 200 L
Inflow (Qin, Pump ON) 20 L/min
Outflow (Qout) 8 L/min
Exact Analysis NET FLOW & DISCRETIZATION
• Pump ON: 20 − 8 = +12 L/min
• Pump OFF: −8 L/min
V(t) = 200 + 12t  [Exact]
Vn+1 = Vn + h·(Qin − Qout)
Comparative Model ADVANCED NON-LINEAR OUTFLOW (FOR BENCHMARKING)
dV / dt = Qin − k·√V,   with k ≈ 0.5657

Calibrated such that Qout = 8 L/min at V = 200 L. The variable slope allows differential truncation error analysis among ODE methods.

Eight Numerical Methods & ODE Solvers

Algorithm taxonomy and mathematical formulation of initial-value problem integration
P1: Imtiyaz Ali
Method Taxonomy EIGHT METHODS GROUPED BY SIMULATION DOMAIN
1. ODE SOLVERS
Euler, Modified Euler, RK4
Water volume trajectory over time V(t)
2. ROOT FINDING
Bisection, False Position, Newton-Raphson
Predicting time to reach target storage volume
3. LINEAR SYSTEMS
Gaussian Elimination, Gauss-Jordan
Three-pipe outflow rate distribution network
Euler's Method Order O(h)
Vn+1 = Vn + h·f(tn, Vn)
Single initial slope evaluation. Simplest formulation with standard linear truncation.
Modified Euler (Heun) Order O(h²)
Vn+1 = Vn + (h/2)(k1 + k2)
k1=f(tn,Vn), k2=f(tn+h, Vn+h·k1)
Predictor-corrector averaging starting and projected interval endpoint slopes.
Runge-Kutta 4th Order Order O(h⁴)
Vn+1 = Vn + (h/6)(k1 + 2k2 + 2k3 + k4)
Simpson's quadrature weighting 4 tangent evaluations per discrete step.
WORKED BENCHMARK STEP: Non-linear model, V0 = 200 L, step h = 5 min  →  Euler: slope 12.000 → V1 = 260.00 L  |  Modified Euler: k1=12.000, k2=10.879 → V1 = 257.20 L
Constant Flow: All 3 Match Exactly

Root-Finding Methods — Predicting Time

Target-level time prediction solving f(t) = V(t) − Vtarget = 0
P1: Imtiyaz Ali
Root Formulation
f(t) = V(t) − Vtarget = 0
Derivative f'(t) = dV/dt (the tank's instantaneous net flow rate)
Algorithm Formulation THREE SOLVER ARCHITECTURES
Method Core Mechanism Iterative Formula
Bisection Halve bracketing interval c = (a + b) / 2
False Position Secant line interpolation c = b − f(b)(b−a) / [f(b)−f(a)]
Newton-Raphson Tangent line from guess tn+1 = tn − f(tn) / f'(tn)
Linear Test Case TARGET: 50% CAPACITY (500 L)
f(t) = 200 + 12t − 500 = 0  →  t = 25.00 min

For linear f(t), both False Position and Newton-Raphson locate the exact root in 1 single step.

Convergence Benchmark ADVANCED MODEL (TARGET 500 L, TOL: 1e-4)
Calculated Root: t ≈ 32.20 min
Method Iterations Convergence Rate
Bisection 19 Linear (Guaranteed)
False Position 10 Superlinear
Newton-Raphson (t0=30) 3 Quadratic (Fastest)

Linear System Methods — Water Distribution

Three-pipe network outflow distribution solved via Gaussian elimination and Gauss-Jordan reduction
P2: Md. Udoy Hossain Joy
Network System Model OUTFLOW SPLIT INTO THREE PIPES: PIPE A (x), PIPE B (y), PIPE C (z)
x + y + z = 8
Total outflow balance
x − y = 1
Pipe A carries 1 L/min > B
y − 3z = 0
Pipe B carries 3× Pipe C
Method 1 GAUSSIAN ELIMINATION (UPPER TRIANGULAR & BACK SUBSTITUTION)
[ 1  1  1 | 8 ]  →  R2 − R1, R3 + 0.5·R2  →  [ 1  1  1  |  8  ]
[ 1 -1  0 | 1 ]                             [ 0 -2 -1  | -7  ]
[ 0  1 -3 | 0 ]                             [ 0  0 -3.5 | -3.5 ]
Back substitution: −3.5z = −3.5  →  z = 1  →  −2y − 1 = −7  →  y = 3  →  x + 3 + 1 = 8  →  x = 4
Method 2 GAUSS-JORDAN REDUCTION (DIRECT READOUT)
x = 4 L/min  |  y = 3 L/min  |  z = 1 L/min
Row reduction continues to Identity matrix [I | b*], eliminating back-substitution.
Analytical Verification RIGOROUS FLOW CHECK
✓ 4 + 3 + 1 = 8 L/min (Conservation satisfied)
✓ 4 − 3 = 1 L/min (Disparity constraint verified)
✓ 3 − 3(1) = 0 L/min (Ratio constraint verified)
